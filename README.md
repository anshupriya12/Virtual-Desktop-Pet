# Virtual Desktop Pet 🐾

A cute animated desktop companion for Windows, powered by Rainmeter.

## Installation

1. **Download the ZIP** containing the `VirtualDesktopPet` skin.
2. **Extract the ZIP**. You should have a folder named `VirtualDesktopPet`.
3. **Install Rainmeter** if you haven't already: https://www.rainmeter.net/
4. Open **Documents** in File Explorer and find the `Rainmeter` folder. Open `Rainmeter\Skins`. If these folders don't exist, launch Rainmeter once and check again.
5. **Cut and paste the extracted `VirtualDesktopPet` folder** into the `Skins` folder. The path should look like this:
   `Documents\Rainmeter\Skins\VirtualDesktopPet\VirtualDesktopPet.ini`

   Make sure `VirtualDesktopPet.ini`, `@Resources`, and `Settings` are directly inside the `VirtualDesktopPet` folder—not inside an extra nested folder.
6. Find the **Rainmeter raindrop icon** in the Windows taskbar notification area. If you don't see it, click the `^` arrow to show hidden icons. Right-click the raindrop and select **Manage**.
7. In the Skins list, expand `VirtualDesktopPet`, select `VirtualDesktopPet.ini`, and click **Load**. If it doesn't appear, click **Refresh all** and check the folder placement.

## Optional: Install the Font

Open the skin folder, go to `@Resources\Fonts`, double-click `Fredoka-SemiBold.ttf`, and click **Install**. The skin can still load without it, but the text may look different.

## Personalize Your Pet

1. Right-click the pet and select **Pet Settings**. You can also load `Settings.ini` from the `VirtualDesktopPet\Settings` entry in Rainmeter's Manage window.
2. To set the name the pet uses for you, click the name input box, type your name, and press **Enter**.
3. Choose a pet: **Penguin**, **Doggo**, or **Catu**.
4. Choose a pet size (**40%**, **55%**, **75%**, or **100%**) or scroll over the pet to resize it.
5. Set reminders to **15, 30, 45, or 60 minutes**, or click **Test Reminder** to preview one.

## Basic Controls

- **Click** the awake pet to interact.
- **Click and drag** the pet to move it around your desktop.
- **Scroll up or down** over the pet to resize it.
- **Sleep:** click the moon icon or right-click the pet and choose **Toggle Sleep Mode**.
- **Wake up:** click the sleeping pet.
- Settings changes apply instantly. To close the settings widget, right-click it and choose **Unload skin**.

## Troubleshooting

- If the skin doesn't appear in Rainmeter, open **Manage** and click **Refresh all**.
- Check that the folder is placed in `Documents\Rainmeter\Skins\VirtualDesktopPet\` and isn't nested twice.
- Confirm `VirtualDesktopPet.ini` is directly inside the `VirtualDesktopPet` folder.
